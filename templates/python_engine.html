🔧 The 5 Pillars of Python's Data Handling Pipeline

1. Context Managers

Safe Stream Opening (with open)

Using Python's with open(filename, mode='r', encoding='utf-8') as f: guarantees that file descriptors are automatically closed even if parsing errors or network interruptions occur, eliminating resource leaks.

2. DictReader & DictWriter

Header-Bound Record Mapping

Instead of relying on fragile numerical indices (row[0]), Python's csv.DictReader maps each line into a Python dictionary keyed by column name, enabling schema changes without breaking legacy data.

3. Type Coercion & Sanitization

String to Native Type Casting

CSV files store all values as plain strings. Python parses string entries into native float, int, and datetime objects, shielding the math engine from NaN and formatting errors.

4. Atomic Mutation & Persistence

In-Memory Updates & File Rewriting

When a student completes a session or quiz, update_or_append_student_csv() loads all rows into memory, updates the student's entry in-place, and rewrites the entire table atomically with writeheader() and writerows().

🧮 Pure Python Mathematical Modeling & Algorithms

No external third-party data science frameworks (like Pandas or NumPy) are required. Every statistical equation is built from mathematical first principles using Python's math module and loops.

1. Pearson Correlation Coefficient (r)

Measures linear dependency between two continuous variables (e.g., Sleep Hours vs. Productivity). Range: [-1.0, +1.0].

r = Σ((x - x̄) * (y - ȳ)) / sqrt( Σ(x - x̄)² * Σ(y - ȳ)² )
data_handler.py — _calculate_pearson_correlation(x_vals, y_vals)
def _calculate_pearson_correlation(x_vals, y_vals):
    n = len(x_vals)
    if n < 2 or len(y_vals) != n:
        return 0.0
    mean_x = sum(x_vals) / n
    mean_y = sum(y_vals) / n
    cov_xy = sum((x - mean_x) * (y - mean_y) for x, y in zip(x_vals, y_vals))
    var_x = sum((x - mean_x) ** 2 for x in x_vals)
    var_y = sum((y - mean_y) ** 2 for y in y_vals)
    denom = math.sqrt(var_x * var_y)
    return round(cov_xy / denom, 3) if denom != 0 else 0.0

2. Dynamic Burnout Risk Index (0 - 100)

A non-linear heuristic combining study fatigue, sleep deprivation penalty, mood resistance, and deadline urgency.

Risk = Clamp( (H_study * 7.5) + ((8.0 - H_sleep) * 12.0) - ((Mood - 1) * 6.0) + (10.0 / (Days + 1)), 5, 98 )

# Sleep deficit penalty: +12 points per hour under 8.0h baseline
sleep_penalty = max(0, (8.0 - sleep_hours) * 12.0)
# Study fatigue load: +7.5 points per study hour
study_load = study_hours * 7.5
# Mood protection buffer: up to -24 points for positive mood
mood_protection = (mood_score - 1) * 6.0
# Deadline proximity multiplier
urgency_load = 10.0 / (days_left + 1)

raw_index = 25.0 + study_load + sleep_penalty - mood_protection + urgency_load
risk_index = int(max(5, min(98, round(raw_index))))

data_handler.py — Atomic CSV Updating with DictReader & DictWriter Standard Library: csv 
def update_or_append_student_csv(user_id):
    """
    Updates or appends a student's metrics to students_data.csv using pure Python CSV file handling.
    Aggregates study sessions, quiz performance, and task statuses directly from relational records.
    """
    user = db.session.get(User, user_id)
    student_record = {
        "Student_ID": str(user.id),
        "Username": user.username,
        "Email": user.email,
        "Registration_Date": user.created_at.strftime("%Y-%m-%d %H:%M:%S"),
        "Total_Sessions": str(len(user.sessions)),
        "Total_Study_Hours": f"{sum(s.study_hours for s in user.sessions):.1f}",
        "Avg_Productivity": f"{(sum(s.productivity_score for s in user.sessions) / max(len(user.sessions), 1)):.1f}",
        "Burnout_Risk": user.sessions[-1].burnout_risk if user.sessions else "Low",
        "Last_Active": datetime.now(timezone.utc).strftime("%Y-%m-%d %H:%M:%S")
    }

    # Safe read with DictReader
    rows = []
    with open(STUDENTS_CSV_FILE, mode="r", newline="", encoding="utf-8") as f:
        reader = csv.DictReader(f)
        for r in reader:
            rows.append(r)

    # Mutate in-memory or append
    updated = False
    for i, row in enumerate(rows):
        if row.get("Student_ID") == str(user.id):
            rows[i] = student_record
            updated = True
            break
    if not updated:
        rows.append(student_record)

    # Safe write with DictWriter
    with open(STUDENTS_CSV_FILE, mode="w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=STUDENTS_CSV_FIELDS)
        writer.writeheader()
        writer.writerows(rows)
    return True
